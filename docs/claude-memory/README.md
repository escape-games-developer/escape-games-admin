# Memoria de Claude

Copia de las notas que Claude Code guarda entre sesiones para este proyecto
(contexto del usuario, preferencias de trabajo, ids y estado de los proyectos).

La memoria activa vive en la máquina del desarrollador
(`~/.claude/projects/<proyecto>/memory/`). Esta copia sirve de respaldo y para
retomar desde otra máquina: copiar estos archivos a esa carpeta.

No guardar acá claves, tokens ni datos personales de clientes: el repo es público.
